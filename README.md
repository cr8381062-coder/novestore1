# Nove Store

Premium FiveM & Discord products storefront.

- Pure HTML / CSS / vanilla JavaScript (no framework, no build step)
- Data stored in `localStorage`
- Client-side authentication (email + password)
- Admin panel for managing products, orders, users, and settings

## Deploy

This is a static site. Deploy the repo root directly (no build command needed).

```toml
[build]
  publish = "."
```
